**Ferramenta escolhida**: Python, com as bibliotecas Pandas, Plotly e Streamlit.

## Passos para rodar o projeto
> Passo 1: possuir Python instalado (preferencialmente a versão 3.12)

> Passo 2: Instalar os requerimentos com o comando ```pip install -r requirements.txt```

> Passo 3: rodar o projeto com o comando ```python3 src/app.py```

## Principais Insights
- O e-commerce está com uma tendência geral de crescimento, não isolado somente ao final do ano. Entretanto, seria bom ter os dados de outros anos para saber se não é um comportamento cíclico.
- Não há um dia da semana em que há mais ou menos compra (de forma significativa), o que é estranho, já que geralmente quartas e quintas costumam ser os dias de pico de vendas.
- O pico de vendas no Natal é feito um dia antes das vésperas. A não ser que os fretes sejam feitos em 1 dia (o que é improvável, mas não impossível), isso quer dizer que a pico de vendas desse período consiste principalmente naqueles que vão dar os presentes atrasados. Isso pode significar que o e-commerce não está anunciando bem no Natal.
- O faturamento geral da empresa vem principalmente de produtos de alto valor agregado (bikes, celulares, etc.)
- Outros insights se encontram no painel mais inferior do dashboard.

## Desafios encontrados
- A biblioteca Pandas é bem complicada, apesar de muito útil, e eu ainda não consegui captar completamente os conceitos dela apesar de conseguir explicar aquilo que usei. Por praticidade fui usando a IA para me instruir a como fazer as coisas.
- Ao decorrer do projeto, percebi que seria conveniente mudar a forma como estava organizando o código, e resolvi modularizar para melhorar a organização. Como eu já havia feito uma quantidade considerável de coisas, pedi para a IA fazer a refatoração, depois continuei seguindo o mesmo padrão.
- Em geral houve outros problemas do tipo: depois de ter feito muita coisa de um jeito percebi que há uma forma melhor de fazer, e para poupar tempo pedi para a IA fazer.
